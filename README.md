# Software Developer Interview Prep Landing Page

An interactive, responsive landing page that helps Delhi NCR developers prepare for a software developer interview. It includes a practice question game, flip cards for the four common interview rounds, a 90 day plan with tabs, a self rating tool and links to guides, courses and a free demo.

## Live preview
Enable GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).

## Files
- `index.html` : the complete page (HTML, CSS and JavaScript in one file)
- `README.md` : this file

## Features
- Fully responsive layout
- Keyboard friendly and reduced motion support
- All links open in a new tab

## Customise
Edit the colour variables at the top of the `<style>` block in `index.html` (`--ink`, `--coral`, `--mint`, `--sun`, `--paper`).
